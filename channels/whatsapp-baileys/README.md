# WhatsApp / Baileys Adapter

Baileys carries inbound and outbound WhatsApp messages. The adapter accepts only exact aliases in ELARA access configuration before doing any work. It restores voice-note transcription when an endpoint is configured, quoted-message context, adaptive typing, emotion styling, bubble formatting, explicit session reset, and principal-scoped memory commands. Approval answers are handled outside the conversation queue and apply only to the matching principal's pending request. Authorization, policy, and computer execution remain in ELARA and DSH.
